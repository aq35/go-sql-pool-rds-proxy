# pat-warmup — db.r6g.large

**問い**: 新しいプールに 32 同時のクエリが来るとき、事前に PingContext を並列で流して接続を作っておくと、最初の波の遅延はどれだけ縮むか(TLS、別 AZ)

**仮説**: 事前に温めない場合、最初の波は、接続の確立(TCP + TLS + ログイン)の分だけ遅く、温めた場合は 2 回目の波と同じ遅延になる。差は、接続 1 本の確立時間(約 20〜30 ms)の数倍までになる。

**読み方**: run(cold と warm)ごとに、summary の w1_p50_ms_med、w1_max_ms_med を比べる(10 回の試行の中央値、さらに 3 回の繰り返しの範囲)。warm_ms_med は、温めるのにかかった時間(起動時に払うコスト)。w2_p50_ms_med は、温まった後の基準値。

値は、繰り返しの中央値 [最小–最大]。
